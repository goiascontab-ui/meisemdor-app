🚀 DEPLOY RÁPIDO NO VERCEL (5 MINUTOS)
═══════════════════════════════════════════════════════════════════════════

1. Extraia o ZIP em uma pasta
2. Abra o terminal na pasta do projeto
3. Execute:

   git init
   git add .
   git commit -m "MEI Sem Dor - Projeto Completo"
   git branch -M main

4. Crie um repositório no GitHub
5. Execute (substitua SEU-USUARIO e SEU-REPO):

   git remote add origin https://github.com/SEU-USUARIO/SEU-REPO.git
   git push -u origin main

6. Acesse https://vercel.com
7. Clique em "Add New Project"
8. Importe seu repositório
9. Configure:
   - Framework: Vite
   - Build Command: npm run build
   - Output Directory: dist
10. Clique em "Deploy"

🎉 PRONTO! Seu site estará online em 2-3 minutos!

═══════════════════════════════════════════════════════════════════════════
🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

❌ Erro ao instalar?
   → Delete node_modules e package-lock.json
   → Execute: npm install

❌ Build falhando?
   → Verifique Node.js versão 18+
   → Execute: npm run build

❌ Página em branco?
   → Verifique console do navegador (F12)
   → Verifique se build foi feito corretamente

❌ Anúncios não aparecem?
   → Aguarde aprovação do AdSense (7-14 dias)
   → Verifique se código está no <head>
   → Desative bloqueadores de anúncios para testar

❌ Erro 404 nas rotas?
   → Verifique se vercel.json está presente
   → Verifique se rewrites estão configurados
