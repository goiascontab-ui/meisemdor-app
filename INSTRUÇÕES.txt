🚀 COMO USAR - OPÇÃO 1: DEPLOY DIRETO NO VERCEL
═══════════════════════════════════════════════════════════════════════════

1. Baixe a pasta "meisemdor" completa
2. Faça upload para o GitHub:
   
   cd meisemdor
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/SEU-USUARIO/meisemdor.git
   git push -u origin main

3. Acesse https://vercel.com
4. Clique em "Add New Project"
5. Importe seu repositório
6. Configure:
   - Framework: Vite
   - Build Command: npm run build
   - Output Directory: dist
7. Clique em "Deploy"
8. PRONTO! Seu site estará online em 2-3 minutos! 🎉

═══════════════════════════════════════════════════════════════════════════

1. Baixe a pasta "meisemdor"

3. Execute:

4. Abra o navegador em: http://localhost:8080
5. Teste todas as funcionalidades
6. Quando estiver satisfeito, faça deploy seguindo OPÇÃO 1

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Erro ao instalar dependências?
→ Delete node_modules e package-lock.json
→ Execute: npm install

Build falhando?
→ Verifique se tem Node.js 18+ instalado
→ Execute: npm run build

Página em branco após deploy?
→ Verifique se o vercel.json está no repositório
→ Verifique se a build command está correta

PDF não gera?
→ Teste localmente primeiro
→ Verifique console do navegador para erros
